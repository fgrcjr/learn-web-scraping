🕷️ Web Scraping Playground

Practice extracting data from every kind of web element — organized from flat & simple to deeply nested & dynamic.

How this page is organized

Each level adds more layers of nesting and more moving parts. Start at Level 1 and work your way down.

  1. Level 1 — Flat elements: single elements, no nesting (headings, text, links, images, attributes)
  2. Level 2 — Simple containers: one layer of nesting (lists, simple tables, forms, media)
  3. Level 3 — Nested structures: 2–3 layers (nested lists, complex tables, card grids, menus, pagination)
  4. Level 4 — Deep & tricky structures: 4+ layers (comment threads, microdata, hidden elements, iframes, messy markup)
  5. Level 5 — Dynamic content: JavaScript-rendered, delayed, on-demand, and anti-bot scenarios
  6. Mini-sites: multi-page crawling practice (quotes, books, countries — replicas of famous practice sandboxes)
  7. Wild HTML corpus + ground truth: hostile pages (malformed, legacy, class-less, international) with labeled answers and a scoring script — for testing a scraper automatically
  8. Real practice sites: live websites that are explicitly safe to scrape

4.3 Messy real-world markup

4.8 Relative dates & international formats

    5.8 Shadow DOM (web components)

    Shadow DOM content is invisible to normal selectors. In Playwright, CSS pierces open shadow roots automatically; in raw JS use element.shadowRoot.querySelector(...).

      🧪 Wild HTML Corpus + Ground Truth

      A scraper that only handles clean modern markup isn't general. These pages are hostile on purpose — and every extraction task in this repo has a labeled answer, so you can score a scraper automatically.

      Hostile pages

      • malformed.html — unclosed lists and table cells, mis-nested <b><i>, unquoted attributes, raw ampersands. Your parser must recover the way browsers do.
      • legacy-layout.html — a 1998-style page: the entire layout is nested tables, everything is <font> tags. Find the one data table among the layout tables.
      • no-semantics.html — zero ids, zero classes, zero semantic tags. Only structure, order, and label text like "Salary:" to anchor on.
      • intl.html — German, Japanese, French, and Arabic (RTL) listings. Normalize every price to a number + ISO currency and every date to ISO 8601.
      • feed.xml — an RSS feed: scrapers must handle XML too.

      Ground truth & automatic scoring

      This is the part that makes the repo a training set, not just a demo: 27 extraction tasks with expected JSON output, an evaluator, and reference scrapers as the answer key.

      Two tiers of tasks:

      1. 14 static tasks — solvable with an HTTP request + HTML parser. Defined in ground-truth/manifest.json; answer key: solutions/reference_scraper.py (BeautifulSoup).
      2. 13 browser tasks — the Level 5 dynamic scenarios above: waiting, clicking, scrolling, shadow DOM, honeypot detection. Defined in ground-truth/browser-manifest.json; answer key: solutions/reference_browser_scraper.py (Playwright).

      Workflow: run your scraper on the sources, write one JSON file per task into a folder, then score it with python3 evaluate.py <your-folder> — order-insensitive (unless the task says otherwise), float-tolerant, regex-matching for intentionally random values, and a diff for every failure. The two reference scrapers together pass 27/27.

      🌐 Graduate to Real Sites (built for scraping practice)

      When this playground feels easy, these public sites exist specifically so you can scrape them legally.

      Safe practice targets on the live web

      • books.toscrape.com — 1,000-book fake store: pagination, categories, ratings-in-class-names, detail pages. The canonical first crawl.
      • quotes.toscrape.com — quotes with tags and microdata, plus variants of the SAME data: /js (JavaScript-rendered), /scroll (infinite scroll), /login (CSRF login), /tableful (messy tables), /random.
      • scrapethissite.com — guided lessons: countries, paginated & searchable hockey-team database (GET forms), AJAX-loaded Oscar data, iframes, and an advanced login/CSRF challenge.
      • webscraper.io/test-sites — fake e-commerce store in several variants (static pagination, AJAX "load more", true AJAX pagination, scroll loading).
      • the-internet.herokuapp.com — dozens of browser-automation challenges: logins, dynamic loading, iframes, hovers, alerts, file downloads.
      • httpbin.org — not HTML but HTTP itself: echoes your headers/cookies/auth so you can see exactly what your scraper sends.
      • Open Library API — real-world book data with an official free API; practice the "skip scraping, use the API" instinct.
      • Wikipedia — tolerant of polite scraping (and offers full database dumps + an API); great for tables and infoboxes. Respect rate limits.

      Everything else on the web: check robots.txt and the site's terms of service first, identify your bot honestly, and rate-limit yourself.
